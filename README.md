# Momo Dog (摸摸狗)

Website for **Momo Dog**, an iPhone app for winding down before bed: stroke the fur of a sleeping dog,
watch it part under your finger and spring back, and let its slow breathing set your pace.

Live at https://sona-orbit.github.io/momo-dog/

- Home, guide and privacy pages in nine languages (English, 繁體中文, 简体中文, 日本語, 한국어, Español, Deutsch, Français, Português do Brasil)
- Plain static HTML and CSS; this repository holds only the generated site
- Made by Sona Orbit. Issues and pull requests are closed; please use "Report a problem" in the app's settings.
